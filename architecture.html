LAO installs per user with no root service or separate runtime package. Install verifies or reuses MiniLM, OpenCode, llama.cpp, and Qwen3, then the optimizer warms both harness paths. lao status reports non-secret readiness. User-managed vLLM routing and protected vLLM/SGLang-compatible endpoints remain optional, uncertified alternatives behind the same APIs.

2. Trust boundaries

Files

A Local worker may read and edit only the paths named in its packet.

Decision

Planning, uncertainty, or classifier failure means Cloud.

Secrets

OpenCode and the local model never receive harness provider credentials.

Only lao.execute is pre-approved. OpenCode has no shell or network tool and cannot widen the named-file boundary. Codex or Claude reviews the result and runs verification.

Why a monorepo?

Contracts and consumers can change atomically while the project is young. Package boundaries—not repository boundaries—enforce ownership. A component can move out later without changing its API.

What is a component?

Usually one api/x package plus one svc/x package. An app selects implementations and gives them a process.

What is private?

State, migrations and sensitive internal stages. Credentials remain inside svc/gate. If capture is implemented and enabled later, raw content stays inside svc/capture.

6. The architecture is executable

cargo xtask check

Rejects forbidden imports, cycles, state collisions, hidden paths and policy mistakes.

cargo test --workspace

Builds every package and runs boundary and linked/RPC conformance tests.

cargo xtask extract

Builds a fake component outside the repo using only public seams.
