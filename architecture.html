You never code inside lao, and it is not in the request path. Synthetic compatibility, caller-token delivery, the firewall model, and one private Hyper exchange are proven. Daemon wiring, TLS/DNS, config writes, local routing, broader client surfaces, and real-subscription smoke tests remain off.

2. How Codex and Claude connect

P0-04/P0-05 target: the commands stay familiar. Their managed settings point model requests at one supervisor-owned loopback gate. Each client gets its own private caller token. Native provider credentials stay separate.

Codex

codex → provider “lao” → /oai + X-LAO-Key → gate
  • Reuses Codex native auth. LAO does not read its auth files.
  • Uses HTTP/SSE first. No WebSocket fallback dance.
  • Proven synthetically with codex exec 0.146.0.
  • User config can also affect the Codex IDE extension.

Claude Code

claude → /ant + X-LAO-Key → gate
  • Uses the official gateway base URL and a custom caller header.
  • The harmless HEAD hello probe is the only token-free request.
  • Observed on 2.1.223. Re-probe the documented 2.1.227+ before support.
  • Remote Control is disabled by a custom base URL.

The two caller tokens are different and plaintext in owner-only settings; these clients have no Keychain custom-header resolver. A token authenticates only the caller, so launchd must own the socket before activation and through daemon crashes. Same-user malware is out of scope. The firewall proof uses synthetic credentials only.

Transport slice: one narrow Hyper HTTP/1 stack consumes the caller token and streams one synthetic exchange. Policy is still separate and the daemon must not call it yet. Rustls, native TLS identity, and DNS policy are next; no redirect layer will be added.

Why a monorepo?

Contracts and consumers can change atomically while the project is young. Package boundaries—not repository boundaries—enforce ownership. A component can move out later without changing its API.

What is a component?

Usually one api/x package plus one svc/x package. An app selects implementations and gives them a process.

What is private?

State, migrations and sensitive internal stages. Credentials remain inside svc/gate. Raw captured content remains inside svc/capture.
