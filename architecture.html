Why a monorepo?

Contracts and consumers can change atomically while the project is young. Package boundaries—not repository boundaries—enforce ownership. A component can move out later without changing its API.

What is a component?

Usually one api/x package plus one svc/x package. An app selects implementations and gives them a process.

What is private?

State, migrations and sensitive internal stages. Credentials remain inside svc/gate. Raw captured content remains inside svc/capture.

6. The architecture is executable

cargo xtask check

Rejects forbidden imports, cycles, state collisions, hidden paths and policy mistakes.

cargo test --workspace

Builds every package and runs boundary and linked/RPC conformance tests.

cargo xtask extract

Builds a fake component outside the repo using only public seams.

Solid boxes = always-on path. Dashed boxes = optional path. Package metadata in each Cargo.toml is the source of truth.
